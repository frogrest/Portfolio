FrogPOS

A production point-of-sale platform for Filipino stores — live at frogrest.com. Built with a React + TypeScript frontend, a Hono API, and serverless PostgreSQL, it ships offline-first reliability, QR self-ordering, a kitchen display system, ingredient-based inventory, and customer credit tracking.

Problem. A dead signal or a crashing cashier app means lost sales for small restaurants. POS tools need to keep working the moment the internet drops — and be affordable enough for neighborhood stores.

Approach. A multi-tenant SaaS where every store gets isolated, secure data with the features of an enterprise POS out of the box:

  • Offline-first PWA — sales queue locally and auto-sync when the signal returns
  • Multi-tenant SaaS — self-serve signup, subscriptions, and row-level security per store
  • QR self-ordering, real-time kitchen display, split billing, and 80mm thermal receipts
  • Full English / Tagalog localization

Impact. A complete POS product — from database schema to thermal receipts — architected, built, and deployed end-to-end for real Filipino stores.

Restaurant Bot

A state-driven conversational interface for food ordering, built with zero dependencies. A compact state machine moves the conversation from greeting to checkout, and the chat window is wired with aria-live so screen readers announce new messages.

  • State-machine conversation flow — start, shopping, and checkout states
  • Input resolution — category aliases, item IDs, and fuzzy name matching
  • XSS-safe rendering with output escaping
  • Keyboard-first input with ARIA wiring throughout
