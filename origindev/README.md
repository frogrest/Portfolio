# Origin UI (`origindev`) Hub

A structured directory for **Origin UI** components, integration guidelines, and AI agent instructions.

## What is Origin UI?
[Origin UI](https://originui.com) (`origin-space/originui`) is an open-source collection of accessible, copy-and-paste React components built with **Tailwind CSS** and **Radix UI** primitives. It focuses on micro-interactions, accessibility (WCAG 2.1 AA), and modern design aesthetics.

## Folder Contents
- **[`docs/`](./docs/)**: Operating instructions, AI guidelines, and component categories.
- **[`components/`](./components/)**: Accessible component recipes (Inputs, Badges, Switches, Buttons) adhering to Origin UI standards.
