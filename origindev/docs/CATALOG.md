# Origin UI Component Catalog Reference

Quick reference for component types available in Origin UI (`originui.com`):

| Category | Component Pattern | Typical Use Case |
|---|---|---|
| **Inputs** | `InputWithLabel`, `InputWithIcon`, `InputWithFloatingLabel` | Forms, search bars, inquiry inputs |
| **Buttons** | `ButtonWithIcon`, `GlowButton`, `LoadingButton` | Call to action, submissions |
| **Badges & Tags** | `StatusBadge`, `PingBadge`, `FilterBadge` | Tech stack tags, availability badges |
| **Switches & Toggles** | `AccessibleSwitch`, `IconToggle` | Dark mode toggles, filter toggles |
| **Notifications** | `ToastAlert`, `InlineBanner` | Form confirmation, status banners |
| **Dialogs & Popovers** | `AccessibleModal`, `DetailSheet` | Project preview modals, quick bio sheet |
