# React Bits Hub

A structured workspace for **React Bits** animations, dependencies, and AI agent operating manuals.

## Directory Layout
- **[`dependencies/`](./dependencies/)**: Installation instructions, peer dependency manifests, and CLI recipes.
- **[`animation/`](./animation/)**: Clean TypeScript + Tailwind CSS animations (`SplitText`, `BlurText`, `ShinyText`, `DecryptedText`).
- **[`docs/`](./docs/)**: In-depth instructions, architecture rules, and common anti-patterns for AI coding agents.
- **[`instructions/`](./instructions/)**: Quick references and orientation guides for autonomous tools.
